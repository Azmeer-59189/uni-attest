# Creative UI/UX

## Understand the project

- Inspect the existing application, components, and brand guidelines.
- Identify the audience, main tasks, and technical constraints.
- Preserve the existing visual identity unless a redesign is requested.

## Explore design directions

For a new design or major redesign:

- Explore at least three visually different directions.
- Vary layout, typography, color, imagery, and visual hierarchy.
- Explain which direction best suits the project and why.
- Wait for the user to choose when they ask to review options first.

## Avoid generic repetition

Avoid defaulting to the same rounded cards, gradient backgrounds,
oversized hero sections, and identical dashboard layouts.

These patterns can be used when they fit the product. Choose design
elements for a reason instead of applying the same style everywhere.

## Build a usable interface

- Make the layout responsive on desktop, tablet, and mobile.
- Use clear typography, spacing, and visual hierarchy.
- Consider keyboard navigation, focus states, and color contrast.
- Include loading, empty, error, and success states where needed.
- Preserve existing functionality.
- Use the project's existing components and libraries when appropriate.

## Animation

- Use animation only where it improves feedback or navigation.
- Prefer CSS for simple transitions.
- Use Motion for React when more advanced animation is useful.
- Respect the user's reduced-motion preference.
- Avoid excessive or distracting effects.

## Verify

- Run the application if possible.
- Inspect the affected pages at desktop and mobile widths.
- Check for overflow, alignment problems, and broken interactions.
- Fix issues found and explain what could not be verified.
